# 🚀 Generador de Boletín Informativo - QWASI

Una aplicación web profesional, ligera y elegante diseñada espressamente para agencias que necesitan crear boletines informativos técnicos en segundos, sin complicaciones.

## ✨ Características Principales

### 🎯 Flujo de Trabajo Ágil
1. **Redactar**: Completa el formulario con la información del boletín usando el nuevo **editor de texto rico** (negritas, cursivas, listas).
2. **Categorizar**: Asigna cada bloque de contenido a un área específica (**SST** o **Medio Ambiente**).
3. **Previsualizar**: Observa el resultado en tiempo real en un simulador de cliente de correo.
4. **Copiar y Enviar**: Un clic para copiar el HTML estilizado y pegarlo directamente en Outlook o Gmail.

### 🎨 Diseño Corporativo Premium
- Interfaz moderna con paleta de colores corporativos.
- Tipografía clara (Inter) y jerarquía visual optimizada.
- Diseño de bloques mediante tarjetas (cards) para una mejor organización.

### 🔧 Funcionalidades Técnicas
- ✅ **Autoguardado (LocalStorage)**: Tu progreso se guarda automáticamente en el navegador. Nunca perderás lo que has escrito.
- ✅ **Clasificación por Áreas**: Soporte para etiquetas automáticas de "Seguridad y Salud en el Trabajo (SST)" y "Medio Ambiente".
- ✅ **100% Frontend**: Basado en Astro y JS Vainilla. Sin base de datos, rápido y privado.
- ✅ **Compatibilidad Total**: HTML generado específicamente para clientes de correo de escritorio con tablas y estilos inline.
- ✅ **Zero-Fricción**: Sin registros ni configuraciones complejas.

## 🚀 Instalación y Uso

### Prerrequisitos
- Node.js 18+ 
- npm o yarn

### Instalación
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

## 🎨 Personalización de Áreas
El sistema está configurado para las dos áreas principales de la agencia:
- **Seguridad y Salud en el Trabajo (SST)**
- **Medio Ambiente**

Estas áreas generan automáticamente etiquetas visuales en el encabezado de cada sección del boletín.
